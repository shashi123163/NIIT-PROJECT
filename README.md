# NIIT Foundation – Web Development Basics Project

## About the Project
This repository contains my project work for the NIIT Foundation Program in Web Development Basics (CLBWD).

The project demonstrates responsive web design, debugging website layout issues, industry exposure, web development skills, and community engagement.

## Project Objectives
- Understand HTML, CSS, and JavaScript fundamentals.
- Identify and fix mobile responsiveness issues.
- Learn about web development companies, roles, and required skills.
- Explore a community problem and propose practical solutions.

## Technologies Used
- HTML5
- CSS3
- JavaScript (fundamentals)
- Visual Studio Code
- Google Chrome DevTools
- Microsoft Excel
- Git and GitHub

## Key Learning Outcomes
- Creating responsive web layouts using CSS.
- Using media queries and flexible image sizing.
- Debugging and testing websites in Chrome DevTools.
- Understanding Git version control and GitHub repositories.
- Exploring industry skills and community problem-solving.
